Fly a small plasticine propeller plane around a sunset archipelago. Everything looks hand-modelled from clay: rounded shapes, thumb-print bumps, saturated colours, cotton-ball clouds and stop-motion-style animation. Complete missions, manage fuel and damage, and land on the runway.

Built with three.js (MIT), vendored as a minified file under game/vendor. Runs fully offline from its own files: no network requests, no CDN, no external assets.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and fly with the mouse or the keyboard.
